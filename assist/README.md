# Framework Assist Pack

This folder is the active reference for humans and agents maintaining @devxcrew/framework.
It uses the CXApp Assist layout without its product-specific plans or lockstep workspace rules.

## Reading order

1. Read AGENT-GUIDE.md.
2. Read governance/rules.md.
3. Read documentation/package-reference.md and the affected public exports.
4. Read operations/versioning.md for tooling or release work.

## Folder guide

- documentation/package-reference.md: ownership, exports, dependencies, integration and limits.
- documentation/project-inventory.md: current repository layout.
- documentation/audit.md: reviewed findings and verification limits.
- documentation/CHANGELOG.md: active version state and history.
- governance/rules.md: maintenance boundaries and checks.
- operations/versioning.md: version, changelog, GitHub and LF commands.

Historical changelog entries are evidence, not current instructions.
